# Maritime OSINT – Vessel Identity & Shadow Fleet Patterns

Evidence-first open-source research on vessel identity reconstruction, historical name and flag changes, ownership/management networks, and indicators associated with shadow fleet operations.

This repository collects structured case notes. All information is drawn from publicly available sources. Conclusions distinguish verified facts from analytical inference.

## Methodology Notes

- Identity continuity is tracked primarily via **IMO number**.
- Name, flag, owner and manager changes are treated as analytical signals, not noise.
- Source discrepancies are preserved and examined rather than resolved by preference.
- Sanctions-related information is recorded with source attribution and date.
